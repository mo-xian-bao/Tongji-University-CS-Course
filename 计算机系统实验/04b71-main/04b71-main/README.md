# BianryViewer（二进制文件查看器）使用说明

## 简介

BinaryViewer（二进制文件查看器）是一款功能强大的二进制文件查看工具。它不仅能够满足您查看二进制文件的需求，还支持显示八进制、十进制以及十六进制代码，让您更方便地阅读和理解文件内容。

## 功能特点

1. **多进制显示**：支持二进制、八进制、十进制和十六进制等多种进制显示方式，满足不同用户的查看需求。
2. **直接编辑**：可直接对文档进行编辑，方便快捷。
3. **界面友好**：界面简洁，操作直观，让您快速上手使用。

## 使用说明

下载并解压BinaryViewer后，您可以直接运行程序开始查看和编辑二进制文件。根据您的需求选择不同的进制显示方式，更方便地阅读和理解文件内容。

如果您在使用过程中遇到任何问题，请查阅相关文档或寻求技术支持。
