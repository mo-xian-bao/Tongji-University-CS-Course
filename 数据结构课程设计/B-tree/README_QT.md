# B-Tree Visualization Qt Project

## 项目文件说明

这个项目实现了一个可视化的B树数据结构演示程序，使用Qt框架开发。

### 文件结构：
```
B-tree/
├── BTreeVisualization.pro    # Qt项目文件
├── main_qt.cpp              # Qt应用程序入口
├── mainwindow.h             # 主窗口头文件
├── mainwindow.cpp           # 主窗口实现
├── mainwindow.ui            # UI界面文件
├── btreewidget.h            # B树可视化组件头文件
├── btreewidget.cpp          # B树可视化组件实现
├── btree.h                  # B树数据结构头文件 (已修改支持Qt)
├── btree.cpp                # B树数据结构实现 (已修改支持Qt)
├── main.cpp                 # 原控制台版本 (可保留作参考)
└── README_QT.md             # 本说明文件
```

## 在Qt Creator中打开项目

1. **打开Qt Creator**
2. **打开项目文件**：
   - 点击 "File" -> "Open File or Project..."
   - 导航到项目文件夹 `d:\desktop\data-structure\B-tree\`
   - 选择 `BTreeVisualization.pro` 文件
   - 点击"Open"

3. **配置项目**：
   - Qt Creator会检测到这是一个Qt项目
   - 选择合适的Kit (通常是Desktop Qt版本)
   - 点击"Configure Project"

## 功能特性

### 🎯 主要功能：
1. **插入关键字** - 在输入框中输入数字，点击Insert按钮
2. **删除关键字** - 输入要删除的数字，点击Delete按钮  
3. **查找关键字** - 输入要查找的数字，点击Search按钮（会高亮显示）
4. **清空B树** - 点击Clear All按钮清空整棵树
5. **插入测试数据** - 点击Insert Test Data按钮插入预设的测试数据
6. **遍历显示** - 点击Traverse按钮显示中序遍历结果

### 🎨 可视化特性：
- **实时可视化**：每次操作后立即更新树的显示
- **节点区分**：叶节点显示为绿色，内部节点显示为蓝色
- **连接线**：清晰显示父子节点之间的连接关系
- **高亮搜索**：搜索到的关键字会用黄色高亮显示
- **操作日志**：底部显示所有操作的时间戳日志
- **滚动查看**：大型树结构支持滚动查看

### 🔧 界面布局：
- **顶部控制面板**：包含输入框和所有操作按钮
- **中央可视化区域**：显示B树结构，支持滚动
- **底部日志区域**：显示操作历史和状态信息
- **状态栏**：显示当前树的状态

## 编译和运行

### 方法1：在Qt Creator中
1. 打开项目后，点击左下角的"绿色播放按钮"进行编译和运行
2. 或使用快捷键 Ctrl+R

### 方法2：命令行编译（需要安装Qt）
```bash
cd "d:\desktop\data-structure\B-tree"
qmake BTreeVisualization.pro
make
# 然后运行生成的可执行文件
```

## 使用说明

1. **启动程序**：程序启动后会显示一个空的B树
2. **插入测试数据**：建议先点击"Insert Test Data"按钮插入一些测试数据
3. **观察结构**：观察B树的结构，注意叶节点（绿色）和内部节点（蓝色）
4. **尝试操作**：
   - 插入新的关键字，观察树如何平衡
   - 删除关键字，观察节点如何合并或借用
   - 搜索关键字，观察高亮效果
5. **查看日志**：底部的日志区域会显示所有操作的详细信息

## 技术实现细节

- **B树阶数**：当前实现为3阶B树（最多2个关键字，最多3个子节点）
- **删除算法**：完整实现了B树的删除操作，包括借用和合并
- **可视化算法**：自动计算节点位置，绘制连接线
- **Qt组件**：使用QWidget自定义绘制，QPainter进行图形绘制

## 故障排除

如果遇到编译问题：
1. 确保安装了Qt 5.x 或 Qt 6.x
2. 确保选择了正确的Kit
3. 检查是否缺少Qt模块（主要需要Qt Core和Qt Widgets）

如果程序运行异常：
1. 检查控制台输出的错误信息
2. 确保输入的是有效的整数
3. 重启程序重新开始
