## 📋 使用步骤

### 方法1：Qt Creator（推荐）
1. 打开Qt Creator
2. File -> Open File or Project
3. 选择 `BTreeVisualization.pro`
4. 配置项目（选择Kit）
5. 点击运行按钮 (Ctrl+R)

### 方法2：命令行构建
```bash
# 确保Qt在PATH中
qmake BTreeVisualization.pro
make  # 或 mingw32-make
# 运行生成的可执行文件
```

### 方法3：使用构建脚本
```bash
# 双击运行
build.bat
```
