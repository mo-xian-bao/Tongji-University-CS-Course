# 数字游戏 - 约瑟夫环变种

这是一个使用Qt实现的可视化数字游戏程序，模拟约瑟夫环问题的变种，其中每次的间隔数由掷骰子决定。

## 游戏规则

1. n个人（编号1,2,...,n）按顺时针方向围成一圈
2. 选择一个人开始掷骰子（1-6点）
3. 从掷骰子的人开始，按顺时针方向从1开始报数
4. 报到骰子点数时停止，报到该数字的人出列
5. 从出列者的下一个人继续掷骰子
6. 重复上述过程，直到只剩一个人获胜

## 功能特点

- **可视化界面**：圆形排列显示所有参与者
- **动画效果**：计数过程动画显示
- **实时日志**：详细记录游戏过程
- **步进控制**：可以逐步执行游戏过程
- **结果统计**：显示淘汰顺序和最终获胜者

## 编译要求

- Qt 6.0 或更高版本
- C++17 支持的编译器
- CMake 3.16+ 或 qmake

## 编译方法

### 方法一：使用CMake
```bash
mkdir build
cd build
cmake ..
cmake --build .
```

### 方法二：使用qmake
```bash
qmake NumberGame.pro
make  # Linux/Mac
nmake # Windows with MSVC
mingw32-make # Windows with MinGW
```

### 方法三：使用Qt Creator
1. 打开Qt Creator
2. 文件 -> 打开文件或项目
3. 选择 `NumberGame.pro` 或 `CMakeLists.txt`
4. 配置项目并编译

## 使用说明

1. **设置人数**：在"游戏设置"区域输入参与人数（3-20人）
2. **开始游戏**：点击"开始游戏"按钮初始化游戏
3. **执行步骤**：点击"下一步"按钮执行每一轮游戏
4. **查看结果**：在游戏日志中查看详细过程和最终结果
5. **重置游戏**：点击"重置游戏"按钮开始新的游戏

## 界面说明

- **游戏圆圈**：可视化显示所有参与者的位置和状态
  - 绿色：活跃参与者
  - 蓝色：正在计数的参与者
  - 黄色：当前掷骰子的参与者
  - 红色：已被淘汰的参与者
  - 金色：最终获胜者

- **游戏日志**：显示详细的游戏过程记录
- **状态信息**：显示当前游戏状态和骰子点数
- **进度条**：显示游戏进度
