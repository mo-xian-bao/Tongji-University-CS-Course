### 数据报网络 vs 虚电路网络 比较表

| 比较项目 (Issue)             | 数据报网络 (Datagram)                                  | 虚电路网络 (Virtual-circuit)                             |
| :--------------------------- | :----------------------------------------------------- | :------------------------------------------------------- |
| **连接建立** (Circuit setup) | **不需要**。随时可以发包，没有预先握手的过程。         | **必须有**。在发送数据前，必须先建立虚电路连接。         |
| **寻址方式** (Addressing)    | 每个分组（包）都包含**完整的源地址和目的地址**。       | 每个分组只包含一个**短的虚电路号（VC ID）**。            |
| **状态信息** (State info)    | 路由器**不维护**连接的状态信息。                       | 路由器必须为**每一条连接**在路由表中留出存储空间。       |
| **路由选择** (Routing)       | 每个分组**独立选路**。两个包的路径可能不同。           | 在连接建立时**选定路径**，所有分组都沿此固定路径走。     |
| **故障影响** (Failures)      | **影响小**。路由器坏了包会自动绕路，只丢掉崩溃时的包。 | **影响大**。路由器一坏，所有经过它的虚电路**全部中断**。 |
| **服务质量** (QoS)           | **很难保证**。因为路径和资源是不确定的。               | **容易保证**。可以提前为这条虚电路预留带宽等资源。       |
| **拥塞控制** (Congestion)    | **很难**。因为网络无法预测和控制流量的进入。           | **容易**。若网络太挤，可以直接拒绝新的虚电路请求。       |

---

### 💡 深度解析：这两个到底是什么？

为了让你秒懂，可以用**“邮政 vs 电话”**来类比：

#### 1. 数据报网络 (IP网络的逻辑) —— 像“寄平信”
*   **逻辑**：你写好信封（完整地址），扔进邮筒。邮递员看到信封，根据当前路况决定怎么走。
*   **特点**：
    *   **鲁棒性极强**：互联网（IP）采用这种方式。即使某条线路断了，包也会自动绕行。
    *   **效率高但不可靠**：路由器不需要记住谁是谁，转发速度快，但不能保证谁先到。

#### 2. 虚电路网络 (ATM/X.25的逻辑) —— 像“打固定电话”
*   **逻辑**：你先拨号，电信局在你们两个之间接通一条物理/逻辑线路。通话期间，这条线归你，挂断后才释放。
*   **特点**：
    *   **质量有保障**：因为路已经“包”下来了，不会有抢路的情况，适合语音和视频。
    *   **脆弱性**：一旦中间有个中继器坏了，通话立刻断掉，必须重新拨号。

### 总结考点：
*   **数据报**是互联网的设计初衷，追求的是**简单、灵活、抗造**。
*   **虚电路**是早年电信运营商的设计思路，追求的是**可控、稳定、高质量**。

**目前现状**：互联网（数据报）大获全胜。虽然虚电路在某些特定的骨干网技术（如MPLS）中还有应用，但我们现在用的 IP 网络本质上就是数据报网络。

### 一、 路由器和交换机的区别

| 特性         | 交换机 (Switch)                         | 路由器 (Router)                        |
| :----------- | :-------------------------------------- | :------------------------------------- |
| **工作层次** | 主要工作在 **OSI 第二层（数据链路层）** | 工作在 **OSI 第三层（网络层）**        |
| **转发依据** | 依据 **MAC 地址** 转发数据帧            | 依据 **IP 地址** 转发数据包            |
| **主要功能** | 在局域网内部连接设备，构建网络          | 连接不同的网络（如连接局域网到互联网） |
| **广播域**   | 默认不分割广播域（全员广播）            | **分割广播域**（阻止广播包跨网络传播） |
| **主要任务** | 扩大网络接口数量，让多台电脑能互联      | 路径选择（寻址）、网络互连、防火墙功能 |

**通俗比喻：**
*   **交换机**：像是一栋大楼里的**电梯**，负责把人（数据）送到这栋楼里的不同房间（电脑）。
*   **路由器**：像是一个**邮局/海关**，负责把包裹（数据）从一个城市（网络）发送到另一个城市（网络）。

#### 路由器的 IP 配置
路由器的**每一个物理接口**通常都需要配置 IP 地址，因为每个接口连接的是不同的网段。

#### 交换机的 IP 配置
这是一个误区：**普通二层交换机的物理接口是不配置 IP 的**（它们只认 MAC 地址）。交换机的 IP 是配置在 **虚拟接口（VLAN）** 上的，主要用于**远程管理**（如 SSH、Telnet 登录）。

### 总结
1.  **路由器配置 IP** 是为了**干活**（路由转发、作为网关）。
2.  **交换机配置 IP** 是为了**被管**（网管远程登录配置），物理口通常不带 IP。
3.  如果是**三层交换机**，则可以将物理接口转换为“路由接口”（使用 `no switchport` 命令），之后就可以像路由器一样直接在物理口配置 IP 了。
