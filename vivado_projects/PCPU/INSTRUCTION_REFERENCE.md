# 指令编码快速参考

## 指令操作码 (6位)

| 指令  | 操作码 | 十六进制 | 格式 | 功能描述                   |
| ----- | ------ | -------- | ---- | ----------------------- |
| NOP   | 000000 | 0x00     | R    | 空操作                  |
| HALT  | 000001 | 0x01     | R    | 停机                    |
| ADD   | 000010 | 0x02     | R    | rd = rs + rt (有符号)   |
| SUB   | 000011 | 0x03     | R    | rd = rs - rt (有符号)   |
| AND   | 000100 | 0x04     | R    | rd = rs & rt            |
| OR    | 000101 | 0x05     | R    | rd = rs | rt            |
| XOR   | 000110 | 0x06     | R    | rd = rs ^ rt            |
| SLL   | 000111 | 0x07     | R    | rd = rt << shamt        |
| SRL   | 001000 | 0x08     | R    | rd = rt >> shamt (逻辑) |
| SRA   | 001001 | 0x09     | R    | rd = rt >> shamt (算术) |
| CMP   | 001010 | 0x0A     | R    | 比较rs和rt              |
| LOAD  | 001011 | 0x0B     | I    | rd = MEM[rs + imm]      |
| STORE | 001100 | 0x0C     | I    | MEM[rs + imm] = rt      |
| ADDI  | 001101 | 0x0D     | I    | rt = rs + imm           |
| BZ    | 001110 | 0x0E     | I    | if(Zero) PC+=imm<<2     |
| BN    | 001111 | 0x0F     | I    | if(Negative) PC+=imm<<2 |
| JMP   | 010000 | 0x10     | J    | PC = addr               |

## 指令格式

### R型指令 (算术/逻辑运算)
```
 31    26 25   21 20   16 15   11 10    6 5     0
[opcode][  rs  ][  rt  ][  rd  ][shamt ][保留 ]
   6位    5位     5位     5位     5位     6位
```

**示例**：
- `ADD $4, $1, $2` → `0x08220000`
  - opcode=02, rs=1, rt=2, rd=4

### I型指令 (立即数/访存/分支)
```
 31    26 25   21 20   16 15              0
[opcode][  rs  ][  rt  ][      imm       ]
   6位    5位     5位         16位
```

**示例**：
- `ADDI $1, $0, 5` → `0x34010005`
  - opcode=0D, rs=0, rt=1, imm=5
- `LOAD $3, 8($2)` → `0x2C430008`
  - opcode=0B, rs=2, rt=3, imm=8

### J型指令 (跳转)
```
 31    26 25                           0
[opcode][           addr               ]
   6位              26位
```

**示例**：
- `JMP 0x00400010` → `0x40000004`
  - opcode=10, addr=0x400010>>2

## ALU控制信号 (4位)

| ALU操作          | aluc值 | 对应指令               |
| ---------------- | ------ | ---------------------- |
| ADD (有符号加法) | 0010   | ADD, ADDI, LOAD, STORE |
| SUB (有符号减法) | 0011   | SUB, CMP               |
| AND (按位与)     | 0100   | AND                    |
| OR (按位或)      | 0101   | OR                     |
| XOR (按位异或)   | 0110   | XOR                    |
| SLL (逻辑左移)   | 1110   | SLL                    |
| SRL (逻辑右移)   | 1101   | SRL                    |
| SRA (算术右移)   | 1100   | SRA                    |

## 手工编码示例

### 示例1：`ADDI $1, $0, 5`
```
指令字段：
  opcode = 001101 (ADDI)
  rs     = 00000  ($0)
  rt     = 00001  ($1)
  imm    = 0000000000000101 (5)

二进制：001101 00000 00001 0000000000000101
十六进制：0x34010005
```

### 示例2：`ADD $4, $1, $2`
```
指令字段：
  opcode = 000010 (ADD)
  rs     = 00001  ($1)
  rt     = 00010  ($2)
  rd     = 00100  ($4)
  shamt  = 00000
  funct  = 000000 (保留)

二进制：000010 00001 00010 00100 00000 000000
十六进制：0x08220000
```

### 示例3：`BN $15, $16, -3`
```
指令字段：
  opcode = 001111 (BN)
  rs     = 01111  ($15)
  rt     = 10000  ($16)
  imm    = 1111111111111101 (-3的补码)

二进制：001111 01111 10000 1111111111111101
十六进制：0x3DF0FFFD
```

## 控制信号

| 信号      | 功能                                   |
| --------- | -------------------------------------- |
| reg_write | 寄存器写使能                           |
| mem_read  | 内存读使能                             |
| mem_write | 内存写使能                             |
| alu_src   | ALU第二操作数选择 (0=寄存器, 1=立即数) |
| reg_dst   | 目标寄存器选择 (0=rt, 1=rd)            |
| branch    | 分支指令标志                           |
| jump      | 跳转指令标志                           |

## 快速汇编技巧

### 1. 加载常量
```assembly
ADDI $1, $0, 100    ; $1 = 100
```

### 2. 寄存器复制
```assembly
ADD $2, $1, $0      ; $2 = $1
```

### 3. 取反
```assembly
XOR $2, $1, $31     ; 如果$31全为1，则$2 = ~$1
```

### 4. 乘以2的幂
```assembly
SLL $2, $1, 3       ; $2 = $1 * 8
```

### 5. 除以2的幂
```assembly
SRL $2, $1, 2       ; $2 = $1 / 4 (无符号)
SRA $2, $1, 2       ; $2 = $1 / 4 (有符号)
```
