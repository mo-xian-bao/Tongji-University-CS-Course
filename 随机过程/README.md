# 随机过程

教师：汪子乔

课程评价：我反正是听不懂，主要上课也没认真听。这课我们这届只有拔尖班和大数据专业要上，在我们那年还是很轻松的，没有期末考只有几次大作业。
但是据子乔所说他决定在我们下一届开始设置期末考试，实在是太邪恶了！（bushi）不知道对计算机专业有何用处，反正子乔原话是他没见过世界上有几所学校的本科生要修这个课的

教师评价：夯爆了！子乔是我本科时期跟随的科研导师，为人十分和善，和学生就像是好友，见多识广谈吐不凡且很大方。学术能力很强，是学校很年轻的海优和副教授。会手把手教你读论文写论文。
建议想在同济继续深造的同学们多联系子乔老师。我研究生阶段离开了同济，没有继续做他的学生，非常非常遗憾，也不知道我的选择是否正确呢
