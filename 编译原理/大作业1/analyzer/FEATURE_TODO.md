# 编译原理作业一功能对照与 TODO

本文档依据 `requirements.pdf` 与当前项目代码整理，重点对照词法分析器、语法分析器以及作业交付物的完成情况。

## 1. 已完成功能

### 1.1 词法分析

当前实现位置：`src/lexer.py`、`src/tokens.py`。

已完成：

- 能识别关键字：`i32`、`let`、`if`、`else`、`while`、`return`、`mut`、`fn`、`for`、`in`、`loop`、`break`、`continue`。
- 能识别标识符，规则为字母或下划线开头，后接字母、数字或下划线；例如 `if123` 会被识别为标识符。
- 能识别十进制整数。
- 能识别赋值号与基础运算符：`=`、`+`、`-`、`*`、`/`、`==`、`!=`、`>`、`>=`、`<`、`<=`、`&`。
- 能识别界符和分隔符：`(`、`)`、`{`、`}`、`[`、`]`、`;`、`:`、`,`。
- 能识别特殊符号：`->`、`.`、`..`、`#`。
- 能跳过空白字符、`//` 行注释、`/* ... */` 块注释。
- 能记录 token 的行号和列号，并在非法字符、未闭合块注释时给出词法错误。

### 1.2 语法分析

当前实现位置：`src/parser.py`、`src/ast_nodes.py`。

已完成：

- `0.1` 变量属性：支持 `mut`，并且在变量声明、形参中也支持省略 `mut`。
- `0.2` 类型：支持 `i32`、引用类型、数组类型、元组类型，并使用递归类型 AST 表示。
- `0.3` 左值：支持标识符、解引用、数组下标、元组字段访问形式的左值。
- `1.1` 基础程序：支持由函数声明组成的程序，支持空形参列表、函数体语句块。
- `1.2` 语句串：支持多条语句和空语句 `;`。
- `1.3` 返回语句：支持 `return;` 与 `return 表达式;`。
- `1.4` 函数输入：支持形参列表，例如 `mut a:i32`、`a:i32`。
- `1.5` 函数输出：支持 `-> i32`。
- `2.0` 变量声明：支持 `mut a`、`mut a:i32`，也支持 `a`、`a:i32`。
- `2.1` 变量声明语句：支持 `let mut a;`、`let mut a:i32;` 等。
- `2.2` 赋值语句：支持 `a = 表达式;`。
- `2.3` 变量声明赋值语句：支持 `let mut a=1;`、`let mut b:i32=1;`、`let a=1;`。
- `3.1` 基本表达式：支持数字、标识符、括号表达式。
- `3.2` 比较运算：支持 `==`、`!=`、`>`、`>=`、`<`、`<=`。
- `3.3` 加减运算：支持 `+`、`-`，并按左结合解析。
- `3.4` 乘除运算：支持 `*`、`/`，优先级高于加减。
- `3.5` 函数调用：支持 `foo()`、`foo(1, a + 2)` 等函数调用表达式。
- `4.1` 选择结构：支持 `if 表达式 { ... }`。
- `4.2` `else`：已额外支持 `else { ... }`。
- `4.3` `else if`：已按独立 `ElseIf` 列表方案实现。
- `5.0` 循环语句入口：已通过 `while`、`for`、`loop` 语句接入循环语句。
- `5.1` `while` 循环：支持 `while 表达式 { ... }`。
- `5.2` `for` 循环：支持 `for mut i in 1..n+1 { ... }`，也支持循环变量类型标注。
- `5.3` `loop` 循环：支持 `loop { ... }`。
- `5.4` `break` 和 `continue`：支持 `break;`、`continue;`。
- `6.2`、`6.3` 引用类型：支持 `&i32`、`&mut i32` 以及递归组合类型。
- `6.4` 借用与解引用：支持 `&a`、`&mut a`、`*a`，并支持 `*a = expr;`。
- `8.1` 数组类型：支持 `[i32;3]` 等数组类型。
- `8.2` 数组表达式：支持 `[1,2,3]`，也可作为 `for` 的可迭代表达式。
- `8.3` 数组下标：支持 `a[0]` 作为表达式和赋值左值。
- `9.1` 元组类型：支持 `()`、`(i32,)`、`(i32,i32)` 等元组类型。
- `9.2` 元组表达式：支持 `()`、`(1,)`、`(1,2)`。
- `9.3` 元组元素：支持 `a.0` 作为表达式和赋值左值。
- `7.0`、`7.1`、`7.2` 表达式块：支持 `{ 语句串 最终表达式 }`，也支持函数体末尾表达式作为返回值。
- `7.3` 选择表达式：支持 `if cond { expr } else { expr }` 作为表达式。
- `7.4` 循环表达式：支持 `loop { break expr; }` 作为表达式。
- 基础语义分析：支持函数表、变量作用域、重复定义检查、未定义变量检查。
- 基础类型检查：支持变量初始化、赋值、函数调用、返回语句、表达式块、if 表达式、loop 表达式、数组、元组、引用相关类型检查。
- 基础可变性检查：支持不可变变量赋值报错、不可变引用写入报错、非法可变借用报错。
- 支持生成 AST，并以 JSON 形式输出。
- 支持基础错误提示，例如缺少分号、缺少右括号、表达式起始符非法等。
- 语法错误在命令行入口中会显示源码行和列指示。

### 1.3 示例与运行
