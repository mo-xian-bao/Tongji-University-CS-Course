# 类 Rust 词法分析 + 语法分析器（最基础要求版）

本项目严格按你给的“最基本要求”实现，不做扩展功能。

实现目标：
- 词法分析：把源代码切分为 Token。
- 语法分析：基于递归下降，判断程序是否符合基础文法，并构建 AST。

## 1. 支持范围（对应最低要求）

### 词法规则
- 关键字：`i32` `let` `if` `else` `while` `return` `mut` `fn`
- 标识符：字母/下划线开头，后接字母数字下划线
- 整数：十进制数字串
- 运算符：`+ - * / = == != > >= < <=`
- 界符与分隔符：`(){}[] ; : , -> #`
- 注释：`//` 行注释，`/* */` 块注释

### 语法规则
已覆盖你要求中的基础规则：
- `0.1` 变量属性：`mut` 或空
- `0.2` 类型：`i32`
- `0.3` 左值：标识符
- `1.1` 基础程序与函数声明
- `1.2` 语句串
- `1.3` 返回语句（`return;` 与 `return 表达式;`）
- `1.4` 函数输入（形参列表）
- `1.5` 函数输出（`-> i32`）
- `2.0` 变量声明（`mut a` / `mut a:i32`）
- `2.1` 变量声明语句（`let ...;`）
- `2.2` 赋值语句（`a = expr;`）
- `3.1` 基本表达式（数字、标识符、括号）
- `3.2` 比较运算（`== != > >= < <=`）
- `3.3` 加减（`+ -`）
- `3.4/3.5` 这里用标准优先级实现了乘除层（`* /`），便于表达式完整工作
- `4.1` if 语句（支持可选 `else`）
- `5.0` 循环语句入口
- `5.1` while 语句

## 2. 项目结构（推荐阅读顺序）

1. `src/tokens.py`：Token 类型定义
2. `src/lexer.py`：词法分析器实现
3. `src/ast_nodes.py`：AST 节点结构
4. `src/parser.py`：递归下降语法分析器
5. `src/main.py`：分析流程（词法 -> 语法 -> 输出）
6. `run.py`：运行入口（默认配置文件在脚本中）
7. `examples/`：示例输入

## 3. 运行方式

环境：Python 3.10+（推荐）

在项目根目录执行：

```bash
python run.py
```

说明：
- 默认读取 `examples/ok_minimal.rs`
- 如需切换输入，直接修改 `run.py` 中的 `INPUT_FILE` 常量即可（不需要命令行参数）

## 4. 示例文件说明

- `examples/ok_minimal.rs`：通过样例
- `examples/err_lex.rs`：词法错误样例（含非法字符）
- `examples/err_parse.rs`：语法错误样例（缺少分号）

## 5. 输出说明

运行后会打印：
- 词法结果（每个 Token 的行列、类型、文本）
- 语法结果（JSON 格式 AST）
- 最终成功或失败信息

## 6. 教学导向说明

本实现遵循“初学者友好”原则：
- 模块拆分清晰
- 命名直观
- 注释尽量解释“为什么这样写”
