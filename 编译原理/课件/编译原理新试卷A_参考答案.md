## 三、DFA 构造与最小化

正规式 `(a|b)*ba` 表示所有以 `ba` 结尾的 `a、b` 串。因此只需记住当前输入串末尾与模式 `ba` 的最长匹配后缀。

构造状态：

- `q0`：尚未匹配到有用后缀，即当前后缀既不是 `b`，也不是 `ba`。
- `q1`：当前最长有用后缀为 `b`。
- `q2`：当前最长有用后缀为 `ba`，是接受状态。

转移分析：

- 在 `q0` 读入 `a`，仍没有得到后缀 `b`，留在 `q0`；读入 `b`，得到后缀 `b`，转到 `q1`。
- 在 `q1` 读入 `a`，得到后缀 `ba`，转到 `q2`；读入 `b`，最长有用后缀仍是 `b`，留在 `q1`。
- 在 `q2` 读入 `a`，当前串末尾不再是 `b` 或 `ba`，转到 `q0`；读入 `b`，末尾为 `b`，转到 `q1`。

转移表：

| 状态 | a | b |
| ---- | - | - |
| `q0` | `q0` | `q1` |
| `q1` | `q2` | `q1` |
| `q2` | `q0` | `q1` |

初态：`q0`。终态：`q2`。

最小化过程：

1. 初始划分为终态和非终态：`{q2}`、`{q0,q1}`。
2. 比较 `q0` 和 `q1`：输入 `a` 时，`q0` 到非终态集合，`q1` 到终态集合，因此二者可区分。
3. 最终划分为 `{q0}`、`{q1}`、`{q2}`，不能继续合并。

所以该 `DFA` 已经是最小 `DFA`。

## 四、文法分析题

原文法：

```text
S → b | Λ | [T]
T → T;S | S
```

### 1. 消去左递归

`S` 没有左递归。`T` 有直接左递归：

```text
T → T;S | S
```

套用公式：

```text
A → Aα | β
```

可改写为：

```text
A  → βA'
A' → αA' | ε
```

因此：

```text
S  → b | Λ | [T]
T  → S T'
T' → ; S T' | ε
```

### 2. 判断是否为 LL(1)

计算 `FIRST` 集：

```text
FIRST(S)  = { b, Λ, [ }
FIRST(T)  = FIRST(S) = { b, Λ, [ }
FIRST(T') = { ;, ε }
```

计算关键 `FOLLOW` 集：

- `T` 出现在 `S → [T]` 中，所以 `] ∈ FOLLOW(T)`。
- `T'` 出现在 `T → S T'` 末尾，所以 `FOLLOW(T') = FOLLOW(T) = { ] }`。

所以：

```text
FOLLOW(T)  = { ] }
FOLLOW(T') = { ] }
```

检查预测分析表是否会冲突：

- `S → b`、`S → Λ`、`S → [T]` 的 `FIRST` 集分别为 `{b}`、`{Λ}`、`{[}`，互不相交。
- `T' → ;ST'` 的 `FIRST` 集为 `{;}`。
- `T' → ε` 需要填入 `FOLLOW(T') = {]}`。
- `{;}` 与 `{]}` 不相交。

因此改写后的文法是 `LL(1)` 文法。

### 3. 预测分析表

|      | b | Λ | [ | ] | ; | # |
| ---- | - | - | - | - | - | - |
| S    | `S→b` | `S→Λ` | `S→[T]` |   |   |   |
| T    | `T→ST'` | `T→ST'` | `T→ST'` |   |   |   |
| T'   |   |   |   | `T'→ε` | `T'→;ST'` |   |

### 4. 输入串 `[b;Λ]#` 的预测分析过程

约定分析栈左端为栈底、右端为栈顶。

| 步骤 | 分析栈 | 剩余输入串 | 动作 |
| ---- | ------ | ---------- | ---- |
| 1 | `# S` | `[ b ; Λ ] #` | 用 `S→[T]` |
| 2 | `# ] T [` | `[ b ; Λ ] #` | 匹配 `[` |
| 3 | `# ] T` | `b ; Λ ] #` | 用 `T→ST'` |
| 4 | `# ] T' S` | `b ; Λ ] #` | 用 `S→b` |
| 5 | `# ] T' b` | `b ; Λ ] #` | 匹配 `b` |
| 6 | `# ] T'` | `; Λ ] #` | 用 `T'→;ST'` |
| 7 | `# ] T' S ;` | `; Λ ] #` | 匹配 `;` |
| 8 | `# ] T' S` | `Λ ] #` | 用 `S→Λ` |
| 9 | `# ] T' Λ` | `Λ ] #` | 匹配 `Λ` |
| 10 | `# ] T'` | `] #` | 用 `T'→ε` |
| 11 | `# ]` | `] #` | 匹配 `]` |
| 12 | `#` | `#` | 接受 |

分析成功，说明 `[b;Λ]` 是该文法的句子。

## 五、循环优化题

原程序：

```text
S := 0
K := 1
L1: T := M * 2
    U := T + K
    S := S + U
    If K = 100 goto L2
    K := K + 1
    goto L1
L2:
```

### 1. 划分基本块

基本块入口包括：程序第一条语句、标号语句、条件跳转或无条件跳转之后的语句、跳转目标语句。

划分为：

```text
B1:
    S := 0
    K := 1

B2:
L1: T := M * 2
    U := T + K
    S := S + U
    If K = 100 goto L2

B3:
    K := K + 1
    goto L1

B4:
L2:
```

### 2. 控制流图

```text
B1 → B2
B2 → B4    条件为真，跳出循环
B2 → B3    条件为假，继续循环
B3 → B2    回到循环入口
```

循环由 `B2、B3` 构成，`B1` 是循环前置区域，`B4` 是循环出口。

### 3. 循环优化

在循环中：

```text
T := M * 2
```

若 `M` 在循环中不被修改，则 `M * 2` 的值每次迭代都相同，是循环不变式，可外提到循环前。

优化后：

```text
B1:
    S := 0
    K := 1
    T := M * 2

B2:
L1: U := T + K
    S := S + U
    If K = 100 goto L2

B3:
    K := K + 1
    goto L1

B4:
L2:
```

优化后的控制流图仍为：

```text
B1 → B2
B2 → B4
B2 → B3
B3 → B2
```

变化在于 `T := M * 2` 从循环体中移到了循环前置块，减少了每次循环中的重复计算。

## 六、目标代码生成题

中间代码：

```text
1. T := A + B
2. U := C - D
3. V := T * U
4. X := V + T
5. Y := X - U
```

出口活跃变量：`X、Y`。

### 1. 待用与活跃信息

从基本块末尾向前扫描。出口处 `X、Y` 活跃，其他临时变量若之后不再使用则不活跃。

| 语句 | 语句执行前的主要待用/活跃信息 | 说明 |
| ---- | ---------------------------- | ---- |
| `T := A + B` | `A(1,活)`, `B(1,活)`, `C(2,活)`, `D(2,活)` | `A、B` 当前语句使用；`C、D` 下一条使用 |
| `U := C - D` | `C(2,活)`, `D(2,活)`, `T(3,活)` | `T` 在第 3 条还要使用 |
| `V := T * U` | `T(3,活)`, `U(3,活)` | `T` 还会在第 4 条再次使用，`U` 还会在第 5 条使用 |
| `X := V + T` | `V(4,活)`, `T(4,活)`, `U(5,活)` | `U` 保留到第 5 条；`X` 在出口活跃 |
| `Y := X - U` | `X(5,活)`, `U(5,活)` | 生成 `Y`，且 `X、Y` 出口活跃 |

执行完第 5 条后，`X、Y` 在基本块出口活跃，因此需要保存。

### 2. 目标代码

一种可行的目标代码如下：

```text
LD  R0, A
ADD R0, B        ; R0 = T
ST  T, R0        ; T 后面还要用，保存

LD  R1, C
SUB R1, D        ; R1 = U
ST  U, R1        ; U 后面还要用，保存

MUL R0, R1       ; R0 = V，此时 R0 原来的 T 已保存
LD  R1, T
ADD R0, R1       ; R0 = X
ST  X, R0        ; X 是出口活跃变量，保存

LD  R1, U
SUB R0, R1       ; R0 = Y
ST  Y, R0        ; Y 是出口活跃变量，保存
```

说明：目标代码不唯一，只要寄存器分配合理，并在必要时保存出口活跃变量即可。

## 七、四元式序列题

待翻译语句：

```text

if C and D then x:=p+q else x:=p-q
```

起始标号为 `200`。

### 回填思路

1. `while` 条件 `i<j`：
   - 真出口进入循环体。
   - 假出口跳到循环出口。
2. `if C and D`：
   - `C and D` 使用短路求值。
   - `C` 为真才测试 `D`；`C` 为假直接进入 `else`。
   - `D` 为真进入 `then`；`D` 为假进入 `else`。
3. `then` 分支执行完后，需要跳回 `while` 条件开始处。
4. `else` 分支执行完后，也跳回 `while` 条件开始处。

## 八、LR(0) 分析题

文法：

```text
E → T - T | T / T
T → c | d
```

拓广文法编号：

```text
0. E' → E
1. E  → T - T
2. E  → T / T
3. T  → c
4. T  → d
```

### 1. 所有 LR(0) 项目

对每个产生式，在右部所有可能位置加圆点：

```text
E' → ·E
E' → E·

E → ·T-T
E → T·-T
E → T-·T
E → T-T·

E → ·T/T
E → T·/T
E → T/·T
E → T/T·

T → ·c
T → c·
T → ·d
T → d·
```

### 2. 项目集规范族与 DFA

```text
I0:
  E' → ·E
  E  → ·T-T
  E  → ·T/T
  T  → ·c
  T  → ·d

I1:
  E' → E·

I2:
  E → T·-T
  E → T·/T

I3:
  T → c·

I4:
  T → d·

I5:
  E → T-·T
  T → ·c
  T → ·d

I6:
  E → T/·T
  T → ·c
  T → ·d

I7:
  E → T-T·

I8:
  E → T/T·
```

DFA 转换：

```text
I0 --E--> I1
I0 --T--> I2
I0 --c--> I3
I0 --d--> I4
I2 --"-"--> I5
I2 --"/"--> I6
I5 --T--> I7
I5 --c--> I3
I5 --d--> I4
I6 --T--> I8
I6 --c--> I3
I6 --d--> I4
```

### 3. LR(0) 分析表

规约编号：

```text

r2: E → T/T
r3: T → c
r4: T → d
```

| 状态 | - | / | c | d | # | E | T |
| ---- | - | - | - | - | - | - | - |
| 0 |   |   | `s3` | `s4` |   | 1 | 2 |
| 1 |   |   |   |   | `acc` |   |   |
| 2 | `s5` | `s6` |   |   |   |   |   |
| 3 | `r3` | `r3` | `r3` | `r3` | `r3` |   |   |
| 4 | `r4` | `r4` | `r4` | `r4` | `r4` |   |   |
| 5 |   |   | `s3` | `s4` |   |   | 7 |
| 6 |   |   | `s3` | `s4` |   |   | 8 |
| 7 | `r1` | `r1` | `r1` | `r1` | `r1` |   |   |
| 8 | `r2` | `r2` | `r2` | `r2` | `r2` |   |   |

### 4. 是否为 LR(0) 文法

是 `LR(0)` 文法。

理由：分析表中没有同一入口既有移进又有规约，也没有同一入口出现两个不同规约，因此不存在移进-规约冲突和规约-规约冲突。

### 5. 输入串 `c-d#` 的 LR(0) 分析过程

使用上面的分析表。约定栈中交替记录状态和文法符号，初始栈为 `0`。

| 步骤 | 分析栈 | 剩余输入串 | 动作 |
| ---- | ------ | ---------- | ---- |
| 1 | `0` | `c - d #` | `ACTION[0,c]=s3`，移进 `c` |
| 2 | `0 c 3` | `- d #` | `ACTION[3,-]=r3`，按 `T→c` 规约 |
| 3 | `0 T 2` | `- d #` | `ACTION[2,-]=s5`，移进 `-` |
| 4 | `0 T 2 - 5` | `d #` | `ACTION[5,d]=s4`，移进 `d` |
| 5 | `0 T 2 - 5 d 4` | `#` | `ACTION[4,#]=r4`，按 `T→d` 规约 |
| 6 | `0 T 2 - 5 T 7` | `#` | `ACTION[7,#]=r1`，按 `E→T-T` 规约 |
| 7 | `0 E 1` | `#` | `ACTION[1,#]=acc`，接受 |

因此输入串 `c-d#` 可被该 `LR(0)` 分析表接受。

## 九、运行时存储空间组织题

过程静态层次：

```text
P: 0
Q: 1    S: 1
R: 2
```

调用序列为：

```text
P → S → Q → R
```

### 1. 运行栈中的活动记录次序

从栈底到栈顶：

```text
AR(P), AR(S), AR(Q), AR(R)
```

解释：运行栈按动态调用次序增长。虽然 `Q` 和 `S` 都是 `P` 的内层过程，但实际执行时先进入 `S`，再由 `S` 调用 `Q`，再由 `Q` 调用 `R`。

### 2. 动态链和静态链

动态链指向调用本过程前的最新活动记录，即调用者活动记录。静态链指向本过程静态直接外层过程的最新活动记录。

| 活动记录 | 动态链指向 | 静态链指向 | 说明 |
| -------- | ---------- | ---------- | ---- |
| `AR(P)` | 空 | 空 | 主程序无调用者，也无静态外层 |
| `AR(S)` | `AR(P)` | `AR(P)` | `S` 由 `P` 调用，且定义在 `P` 内 |
| `AR(Q)` | `AR(S)` | `AR(P)` | `Q` 由 `S` 调用，但静态外层是 `P` |
| `AR(R)` | `AR(Q)` | `AR(Q)` | `R` 由 `Q` 调用，且定义在 `Q` 内 |

关键区别：`Q` 的动态链指向 `S`，静态链指向 `P`。动态链反映调用关系，静态链反映定义嵌套关系。

### 3. 执行点 X 处 DISPLAY 表

`DISPLAY[k]` 保存当前可见的第 `k` 层最新活动记录地址。执行点在 `R` 中，`R` 的静态外层链为 `R → Q → P`。

| 层次 | DISPLAY 内容 |
| ---- | ------------ |
| 0 | `AR(P)` |
| 1 | `AR(Q)` |
| 2 | `AR(R)` |

注意：`AR(S)` 不在此处 `DISPLAY` 表中，因为 `S` 是动态调用者链上的过程，不是 `R` 的静态外层过程。

### 4. 变量访问

| 变量 | 定义位置 | 层次 | 在 `R` 中是否可按词法作用域访问 | DISPLAY 访问 |
| ---- | -------- | ---- | ------------------------------ | ------------ |
| `a` | `P` | 0 | 可以 | 通过 `DISPLAY[0]` |
| `b` | `Q` | 1 | 可以 | 通过 `DISPLAY[1]` |
| `c` | `R` | 2 | 可以 | 通过 `DISPLAY[2]` 或当前活动记录 |
| `d` | `S` | 1 | 不可以 | 不能通过 `R` 的 DISPLAY 直接访问 |

原因：Pascal 风格静态作用域按程序定义的嵌套结构确定。`S` 虽然在调用序列中位于 `R` 之前，但它不是 `R` 的静态外层，因此 `R` 不能直接访问 `S` 的局部变量 `d`。
