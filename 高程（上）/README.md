# 高级语言程序设计

教师：沈坚

课程评价：是同济计科为数不多的码类课程，对于C语言的学习是有帮助的（在vibe coding时代也没啥用了）。但是课程制度很不合理，作业非常多，老师非常傻逼（沈坚鼎鼎大名）

教师评价：拉完了。在同济的学习时光中，沈坚几乎是我碰到的最烂的老师（之所以是几乎，是因为我在大一上跨文化交际时碰见一位更傻逼的女老师（龚昊航），当时我课上怒喷了她一顿然后退课，后来似乎被开除了反正没见过了）
说回沈坚，怎么说呢，教学能力暂且不论（也就一辈子讲师水平），脑子似乎有点不正常，不会正常回答学生问题，只知道讥讽或者反问，让人听了十分不适。一手设计了只为为难学生的高程课程制度（什么查重啊首行啊），在26年被启迪书院学生联名举报不过并未收敛。QQ群中还有一些他培养的高年级学长助教（有一部分助教很好，乐于回答问题解决困难，也有一些继承了沈坚的刻薄）
不管你选哪个老师，都是沈坚统一管理

## 我始终记得同济一位师姐告诫我的话———越是强者越是谦逊。希望学弟学妹们不要被其影响，向优秀的师长学习
